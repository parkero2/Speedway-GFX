Speedway-GFX Excel Generator (Improved Multi-Sheet)

Excel Structure:

  • Event Info - Venue, event name, lower thirds
  • Schedule - Complete race schedule with feature race flags

How to Use:

  1. Click the button above to generate the Excel file
  2. Open the downloaded file in Excel
  3. Edit the Schedule sheet with your race schedule
  4. Set Feature Race column to "true" for feature races, "false" for heats
  5. Edit the Event Info sheet for venue and lower third templates
  6. Save the file and refresh your schedule.html page
